# Antigravity Project Instructions & UI Design Standards

## UI / UX Architecture: Magic UI Standard
Whenever designing, building, or refining user interfaces, landing pages, or components:
- Utilize **Magic UI** (`magicuidesign/magicui`) design principles, motion aesthetics, and component patterns.
- High-priority components:
  - **Hero & Backgrounds**: `Particles`, `Retro Grid`, `Meteors`, `Interactive Grid Pattern`.
  - **Cards & Borders**: `Border Beam`, `Bento Grid`, `Magic Card`, `Neon Gradient Card`.
  - **Buttons & Call-to-Actions**: `Shimmer Button`, `Shiny Button`, `Interactive Hover Button`.
  - **Text & Accents**: `Blur Fade`, `Hyper Text`, `Number Ticker`, `Word Rotate`.
  - **Carousels & Proof**: `Marquee`, `Animated Beam`.
- Refer to `@skill:magic-ui` for complete React/TypeScript/Tailwind and Vanilla CSS implementations.
