# ETUBU uyarı sesleri (ElevenLabs — SİNAN)

Modüler clip’ler. Cümleler `manifest.json` içindeki `compose` şablonlarıyla birleştirilir.

Örnek:
- Radar + üç yüz metre → `radar` + `d_300m`
- Koridor giriş + hız sınırı + 120 → `koridor_giris` + `hiz_siniri` + `n120`
- Yavaşla → `yavasla`

Eksik (istersen sonra ekle): `d_400m`, `d_550m`
